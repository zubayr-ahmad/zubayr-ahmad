## Projects

### [ClipInsights](https://clipinsights.org)
My final year project, developed with a team of five: a Chrome extension and web
platform for studying YouTube videos through screenshots, timestamped notes,
summaries, key points, transcript-based chat, and PDF export. I built the backend
and browser extension, including AI processing, file and object storage management,
and transcript capture with local storage in IndexedDB.  
`Django` `LangChain` `Pinecone` `TypeScript` `React` `IndexedDB`

### [BooqX](https://booqx.de)
An AI appointment-booking platform for service businesses. I built the core booking
agent with four reusable tools covering business information, availability checks,
booking, rescheduling, and cancellation. It dynamically fetches business and employee
details, allowing new businesses to onboard without changes to the agent.  
`LangGraph` `FastAPI` `LangSmith`

### [ZayG.ai](https://zayg.ai)
An AI chat platform with different conversational personalities. I built the AI
service with short-, medium-, and long-term memory, designed public chat sharing
with minimal data duplication, and implemented subscription-based feature access
and token-bucket usage limits.  
`LangChain` `FastAPI` `Pinecone` `Redis` `Celery`

### [Simpla.ai](https://www.simpla.ai)
An AI platform for tax and accounting guidance and financial document processing.
I applied chunking strategies to improve answer accuracy in its legal RAG system
and integrated financial document-processing platforms into the existing system.  
`Django` `LangChain` `Pinecone` `PostgreSQL` `Elasticsearch`
